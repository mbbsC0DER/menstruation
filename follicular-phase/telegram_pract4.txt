Practical 4: Controlling Raspberry Pi with Telegram

1. Open Telegram on mobile/PC.

2. Open BotFather.

3. Send /start.

4. Create a new bot using /newbot.

5. Give the bot a name and username.

6. Copy the access token provided by BotFather.

7. Clone the professor's GitHub repository:

    git clone https://github.com/salmanfarisvp/TelegramBot.git

8. Enter the cloned directory:

    cd TelegramBot

9. Open the Python file:

    nano telegrambot.py

10. Add the BotFather access token in the code.

11. Save and exit nano.

12. Run the program:

    python telegrambot.py

13. Open your Telegram bot.

14. Send:
    on

    → LED turns ON.

15. Send:
    off

    → LED turns OFF.

16. LED connection:

    LED positive/long leg → Physical Pin 11
    LED negative/short leg → Physical Pin 6 (GND)

17. When finished, deactivate the virtual environment:

    deactivate
